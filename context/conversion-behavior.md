## Fogg MAP — B = Motivation × Ability × Prompt (Homepage / Type 1)

**Motivation:** Surface existing pain — do NOT try to create motivation.
- Owens pain points: regulatory risk, audit failure, cross-border verification gaps.
- Pass: hero addresses a pain point the buyer already has.
- Fail: generic benefit statements ("comprehensive," "reliable") with no specific pain anchor.

**Ability:** Remove every barrier between intent and action.
- Primary CTA: 1 click. Form: ≤5 visible fields. Time to complete: <90 seconds.
- FAQ "Do I need a sales call?" = correct Ability optimization. Removes the highest B2B barrier.

**Prompt:** CTA must appear at every scroll depth.
- Required: Hero + Mid-page (at least one section) + Footer. Missing = Fogg Prompt Fail.
- Dead-scroll zones (2+ viewports with no CTA) = advisory for sticky CTA implementation.

## Fogg Override for Interior Pages (Type 1B)
Replace Motivation evaluation with **Friction Reduction:**
- Does anything on this page make the visitor want to leave before completing their task?
- Unnecessary steps, confusing labels, login walls, multi-step forms before value = friction failures.

## LIFT Model — 6-Factor Scoring (Rate 1–5, maps to 1–10)
Scale: 5=Pass(9–10) | 4=Pass(7–8) | 3=Flag(5–6) | 2=Fail(3–4) | 1=Fail(1–2)

| Factor | Pass Condition | Common Fail |
|---|---|---|
| **Value Proposition** | Quantified benefit above fold | Vague or generic claim |
| **Clarity** | New visitor completes action in <7 seconds | Ambiguous H1 or buried CTA |
| **Relevance** | Hero matches visitor's industry / use case | Generic B2B hero with no vertical signal |
| **Anxiety** | 3+ trust signals visible without scroll | Certifications only, no named proof |
| **Distraction** | ≤3–5 unique CTAs (homepage) / 1–3 (interior) | Competing actions at equal visual weight |
| **Urgency** | Regulatory deadline or time-relevant messaging | No urgency language — most common FAIL |

**Urgency note:** Compliance buyers carry internal deadlines (M&A close, audit window, FATF cycle). Zero urgency = frictionless "I'll come back" exit. Highest-impact LIFT fix on most pages.
