## Core Shift: Stranger → Convert vs. Visitor → Task
Interior pages serve a warm visitor who arrived with intent. Motivation is assumed. Do NOT evaluate motivation creation — evaluate friction reduction.

## Criteria Overrides (Replace Homepage Versions)

| Homepage Criterion | Interior Page Override |
|---|---|
| Hick's Law: 3–5 CTAs | **1–3 CTAs.** Flag 4+ as advisory. Flag 5+ as fail. |
| 5-Second Clarity Test | **Task Clarity Test** (3 questions below) |
| Fogg Motivation | **Friction Reduction:** Does anything make visitor leave before task completion? |
| Social Proof (logo bar above fold) | **Contextual Proof only:** 1 relevant trust signal near primary CTA |
| Full persona coverage | **Primary persona for this page only** |
| Required hero language | **H1 clarity:** does H1 describe exactly what this page delivers? |

## Task Clarity Test (Replace 5-Second Test)
1. **What is this page about?** — Is the page title and opening content immediately clear?
2. **What can I do here?** — Is the primary action visible without scrolling?
3. **Where am I in the site?** — Is the breadcrumb / active nav state visible?

If any answer is unclear → page title, heading hierarchy, or wayfinding requires redesign.

## Buyer Journey Stage Declaration (Required Before Scoring)
Declare before starting: **TOFU** (awareness), **MOFU** (evaluation), **BOFU** (decision). Scoring weight shifts by stage:
- TOFU: content scannability, information scent, new visitor advisory
- MOFU: task completion path, contextual trust, related content
- BOFU: friction reduction, form minimalism, completion feedback

## Must-Check Items (Type 1B)
1. Task Clarity Test — 3 questions answered without scroll
2. Hick's Law — 1–3 unique actions
3. Breadcrumb — present, accurate, clickable
4. Active nav state — current section highlighted
5. H1 ↔ Nav label match — page title matches link that led here
6. Contextual trust signal near primary CTA
7. Related content / next steps at page end
8. "Updated [Month Year]" on compliance/time-sensitive content
9. Mobile table/list reflow
10. Banned language scan (always applies)
11. New Visitor Advisory — if page receives search traffic, orientation hook present?
