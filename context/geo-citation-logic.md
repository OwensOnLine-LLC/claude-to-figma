## AEO vs. GEO Distinction
- **AEO (Answer Engine Optimization):** Structure content for AI direct delivery — zero-click responses, featured snippets, voice answers. Targets: FAQPage schema, BLUF answers, 40–60 word responses.
- **GEO (Generative Engine Optimization):** Optimize for AI citation — getting ChatGPT, Perplexity, Google AIO to reference Owens as a source. Targets: unique data, domain authority signals, human expert claims, information gain over competitors.
- Different strategies. Both matter. GEO is the primary Owens focus.

## Owens Structural GEO Advantages (Primary Drivers)
1. **Domain Heritage (Founded 1992, 34 years):** AI citation engines show strong preference for established domains. Advantage only activates if founding year appears explicitly in on-page content — invisible to AI if not stated.
2. **Human Specialist Network:** "Human investigators conducting in-country verification across 250+ jurisdictions" — no automated competitor can make this claim. Primary GEO citation anchor for all compliance queries.

## Schema Readiness Rating
| Rating | Meaning | Action |
|---|---|---|
| **Schema-Ready** | Content exists, clearly structured, dev can wrap it | PASS |
| **Schema-Possible** | Content exists but needs structural clarification | Flag with note |
| **Schema-Blocked** | Content in graphic/image only — machine-blind | FAIL (design change) |
| **Schema-Absent** | Content does not exist at all | FAIL (content gap) |

## Schema Integrity Guardrail
**Only recommend schema where on-page content explicitly supports it.** Flag as "Schema Risk" if content does not support markup:
- **FAQPage:** Only if discrete Q+A pairs are literally visible and readable.
- **HowTo:** Only if numbered, sequential steps visible to user. NOT for service description pages.
- **ClaimReview:** Only for verifiable regulatory claims (GDPR Article 83, FCRA 604, FATF Rec. 10).
- **Organization:** Always valid when page references company identity, founding date, or certifications.

## Recommended Schema Stacks by Page Type
- Homepage → Organization + ProfessionalService
- Service Page → Service + Organization
- FAQ Page → FAQPage + Organization
- Process / How-It-Works → HowTo + Service
- Compliance / Regulatory → Article + ClaimReview + Organization
- About / Credentials → Organization + ProfessionalService

## Platform Directional Patterns (2026)
Treat as strategic direction, not laws. Human Specialist + Domain Age are always primary.
- **ChatGPT:** Depth + domain authority. Surface heritage + credentials early.
- **Perplexity:** Freshness preference. Compliance pages need quarterly section-level updates.
- **Google AIO:** Diverse authoritative sources. LinkedIn + YouTube extend reach.
- **Bing Copilot:** Authoritative publisher signals. Target industry publication mentions.
